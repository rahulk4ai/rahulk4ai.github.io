AI Career Radar

Privacy policy

Effective 1 November 2026. AI Career Radar is a private personal application operated for its dedicated account owner. It does not accept public sign-ups.

Information accessed and purpose

With the owner's consent, the application uses Google's drive.file permission to create, read and update files it creates or files the owner explicitly opens or selects for it. Those project files can contain job observations, career-policy evaluations, research results, application status, owner feedback, reports and backup snapshots. They support personal career discovery, reporting and recovery. The application does not request access to the owner's entire Drive or Gmail through this authorization.

Storage and processing

Project files are stored in the owner's Google Drive and remain private unless the owner separately authorizes sharing. Minimal canonical job records and decision history are stored in the private project repository on GitHub. Necessary processing runs in the project's managed development environment and, once enabled, its GitHub Actions workflows. These service providers process information as needed to operate and secure the project under their own service terms.

The project uses only relevant résumé facts for matching. It does not commit the raw résumé or unnecessary personal contact details. OAuth credentials are kept in secure secret storage, not in source code or this website; short-lived access tokens are used in memory. Routine logs must not contain credentials or unnecessary personal data.

Use and disclosure

Information is used for the owner's career-research and reporting purposes. It is not sold, used for advertising, or published as a public job-history or résumé profile. AI-assisted analysis, if enabled, is limited to necessary project content through owner-authorized tools and their applicable data controls. Google user data is not used to develop, improve or train generalized AI or machine-learning models.

AI Career Radar's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable.

Retention, deletion and control

Project records are retained for career continuity, deduplication, application history and recovery until the owner directs their removal. Removing a current file or row does not automatically erase version history or backups; deletion requests must account for those copies. The owner can request project-data deletion and credential rotation through the project's normal operating channel.

The owner can revoke the application's Google access under Google Account → Security → third-party connections. Revocation stops future authorized access; it does not delete existing project files or repository copies. Those can be removed separately under the owner's instructions.

This website and contact

This informational website has no forms, analytics scripts, advertising or application data. The hosting provider may retain standard operational/security request logs. For support or privacy questions, use the owner contact displayed on the application's Google consent screen. Policy changes are published here before materially different Google data use is enabled.
